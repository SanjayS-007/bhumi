# Coal Ash Percentage

Ash content of coal on a proximate-analysis basis, as reported in the
Marwatola I&II Geological Report's seam-range summary table (Min/Max per
seam). Reported as a percentage.

## Provenance of this definition

Derived from the real seam_range_summary_table structure observed in the
Marwatola I&II G2 report (docs/REAL_DOC_FINDINGS.md), not from an
illustrative example.
